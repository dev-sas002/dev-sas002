I build backend services and AI features, mostly in Python and TypeScript, with some Ruby on Rails.

Lately most of my work is retrieval and agent pipelines: answers that cite where they came from, and a human approval step before anything changes real data.

**What I work with**

- Backend: Python, Django and DRF, FastAPI, Node.js and Express, Ruby on Rails
- AI and ML: LangGraph, LangChain, ChromaDB, scikit-learn, LightGBM, OpenCV, YOLO
- Frontend: React, Next.js, TypeScript, Tailwind, Angular
- Data and infra: PostgreSQL, MongoDB, Redis, Celery, Sidekiq, Docker, AWS Lambda
